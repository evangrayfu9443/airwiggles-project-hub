## Overview

Airwiggles gives individuals and teams a common web workspace for arranging project work and managing related tasks. By bringing these activities together, it helps keep team coordination and project information in one place.

The tool is built for users who want a direct way to structure projects and maintain visibility into ongoing work. Its collaboration-oriented design supports planning, task tracking, and review from a browser-based interface.

## Using Airwiggles

A basic way to work with Airwiggles is:

1. Launch the application in a web browser.
2. Choose an existing project or create a new one.
3. Enter the tasks that belong to the project.

5. Adjust the project as plans and priorities develop.
